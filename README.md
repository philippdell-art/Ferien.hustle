# Ferien Hustle

Eine moderne, responsive Muster-Website für ein GitHub- oder Webentwicklungs-Tutorial.

## Funktionen

- Responsive One-Page-Website
- Mobiles Navigationsmenü
- Scroll-Animationen
- Interaktiver FAQ-Bereich
- Semantisches HTML und barrierearme Bedienelemente
- Kein Build-Schritt und keine Abhängigkeiten

## Dateien

- `index.html` - Inhalt und Struktur
- `style.css` - Design und responsive Darstellung
- `script.js` - Navigation, Animationen und FAQ-Verhalten

## Lokal starten

Öffne `index.html` direkt im Browser oder starte einen kleinen lokalen Server:

```bash
python3 -m http.server 8000
```

Danach ist die Website unter `http://localhost:8000` erreichbar.

## GitHub Pages

Unter **Settings > Pages** als Quelle **Deploy from a branch** auswählen und anschließend den Branch `main` mit dem Ordner `/ (root)` festlegen.
